# Komentář k zákonu č. 588/2020 Sb., o náhradním výživném pro nezaopatřené dítě a o změně některých souvisejících zákonů (zákon o náhradním výživném)

Otevřený komentář k zákonu o náhradním výživném — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; oprávněné osoby, podmínky nároku, výše, řízení u Úřadu práce, výplata, změna a zastavení, přeplatky, přechod pohledávky na stát a změny souvisejících zákonů.

Konsolidované znění: dokument e-Sbírky `SB-2020-00588_2025-07-01`.
